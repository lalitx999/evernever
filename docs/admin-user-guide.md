# คู่มือหลังบ้าน evernever

## เข้าสู่ระบบ

เปิด `/login` แล้วใช้บัญชี WordPress ที่ผู้ดูแลจัดให้ บัญชี Editor จัดการผลงานได้ ส่วน Administrator แก้ข้อมูลบริษัทได้ด้วย เมื่อเลิกใช้งานกด **ออกจากระบบ**

## ลงผลงานใหม่

1. ไป **ผลงาน → เพิ่มผลงาน**
2. กรอกชื่อและลิงก์หน้า เช่น `brand-campaign-2026` (ไม่ซ้ำผลงานอื่น)
3. ใส่คำอธิบาย รายละเอียด หมวดหมู่ และลิงก์วิดีโอหนึ่งลิงก์ต่อบรรทัด
4. อัปโหลดรูปปกและภาพแกลเลอรี รองรับ JPG / PNG / WebP รูปละไม่เกิน 3 MB
5. ใส่ลำดับ ตัวเลขน้อยอยู่ก่อน เลือก “แนะนำบนหน้าแรก” หากต้องการ
6. ใช้ **ดูตัวอย่าง** เพื่อตรวจเนื้อหา
7. เลือก **ฉบับร่าง** เพื่อเก็บงาน หรือ **เผยแพร่** เพื่อให้แสดงต่อสาธารณะ แล้วกดบันทึก

เมื่อขึ้นข้อความสำเร็จจึงถือว่าบันทึกเรียบร้อย ไม่ต้องเข้า WordPress กดซ้ำ หากเกิดข้อผิดพลาดอย่าปิดหน้า ให้แก้ไขหรือลองใหม่

## แก้ไขและซ่อนผลงาน

ค้นหาจากชื่อแล้วกด **แก้ไขผลงาน** หากต้องการซ่อน เลือกสถานะ **ฉบับร่าง** แล้วบันทึก

หากมีคนอื่นแก้ไขรายการเดียวกัน ระบบจะแจ้งว่าข้อมูลเปลี่ยนแล้ว ให้คัดลอกข้อความที่เพิ่งแก้ไว้ก่อน โหลดรายการใหม่ และแก้ไขบนข้อมูลล่าสุด

## รูปและวิดีโอ

- “นำออก” นำภาพออกจากแกลเลอรีของผลงาน ไม่ลบไฟล์จากคลัง WordPress
- “เลื่อนขึ้น” จัดลำดับภาพในแกลเลอรี
- รองรับการแสดงวิดีโอ YouTube, Vimeo และ Google Drive ตามรูปแบบที่เว็บรองรับ ลิงก์อื่นเปิดในหน้าต่างใหม่
- อัปโหลดรูปแล้วต้องกดบันทึกผลงานอีกครั้ง

## ถังขยะ

กด **ย้ายลงถังขยะ** เพื่อซ่อนและเก็บรายการไว้ชั่วคราว เมื่อต้องการกู้คืน เลือกตัวกรอง **ถังขยะ** เปิดรายการ เปลี่ยนเป็น **ฉบับร่าง** แล้วบันทึก ระยะเวลากู้คืนขึ้นกับการตั้งค่า WordPress จึงไม่ควรใช้ถังขยะเป็นที่เก็บถาวร

## ข้อมูลบริษัท

Administrator เข้าแท็บ **ข้อมูลบริษัท** เพื่อแก้ข้อความแนะนำ ที่อยู่ เวลาทำการ และอีเมลบนเว็บไซต์ อีเมลรับฟอร์มติดต่อเป็นการตั้งค่าระบบแยกต่างหาก ให้แจ้งผู้ดูแลเมื่อต้องการเปลี่ยนผู้รับ

## ระหว่างเตรียมเปิดใช้

หากเห็นข้อความว่าหน้าเว็บยังใช้ผลงานชุดเดิม แสดงว่าระบบยังอยู่ช่วงเตรียมข้อมูล การบันทึกสำเร็จจะยังไม่เปลี่ยนหน้าเว็บจนกว่าผู้ดูแลเปิดใช้ข้อมูล WordPress
